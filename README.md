# WGAN-GP-for-CIFAR-100-TensorFlow-Keras-
A minimal and readable implementation of Wasserstein GAN with Gradient Penalty (WGAN-GP) trained on the CIFAR-100 dataset using TensorFlow 2.x and Keras. The project demonstrates stable GAN training with a convolutional generator and critic, gradient penalty for enforcing the Lipschitz constraint, and multiple critic updates per generator step.
